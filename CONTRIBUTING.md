# Contributing to komo.do-hub

Thanks for your interest in contributing to **komo.do-hub**!
This repository is a learning-driven project focused on experimenting with Android app development, UI flows, and video-coding workflows.

## How You Can Contribute

You’re welcome to contribute in the following ways:

* Bug fixes
* Code improvements or refactors
* UI/UX enhancements
* Documentation improvements
* Feature ideas or small feature additions

## Getting Started

1. Fork the repository
2. Create a new branch from `main`

   ```
   git checkout -b feature/your-feature-name
   ```
3. Make your changes
4. Commit with a clear message

   ```
   git commit -m "Brief description of the change"
   ```
5. Push your branch and open a Pull Request

## Contribution Guidelines

* Keep changes focused and minimal
* Follow existing project structure and naming conventions
* Avoid introducing breaking changes without discussion
* Make sure the app builds and runs before submitting

## Pull Requests

When opening a Pull Request, please include:

* A short description of what you changed
* The reason for the change
* Screenshots or screen recordings if the UI is affected

## Issues & Discussions

If you find a bug or have an idea:

* Open an issue with a clear title and description
* Feel free to suggest improvements or ask questions
